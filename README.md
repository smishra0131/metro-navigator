# Eight Classes Explaition:
LinkedList
This class is a singly linked list stores values in nodes connected by next references. It's built for a sequence of trip-log entries.

HashTable
This class is storing key-value pairs and supports station-to-zone lookups. It's built for station-to-fare-zone directory.

BST
This class is a binary search tree stores key-value pairs in ordered nodes. It's built for an alphabetically searchable station directory.

MinHeap
This class is a priority structure. It's built for maintenance tasks ordered by numeric priority.

Graph
This class is stores vertices and the connections between them. It's built for stations and direct, unweighted connections.

Stack
This class models the rider Back button. It's built for a rider's Back button/history.

Queue
This class models a service line where the first person to arrive is served first. It's built for a first-come, first-served service line.

HashSet
This class stores unique strings without promising an order. It's built for unique station names and shared-neighbor comparisons.
